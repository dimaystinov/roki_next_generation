# OpenVINO 2026.0 + NCS2: передача разработчику образа

Реализован **нативный плагин MYRIAD для нового OpenVINO**, импортирующий
MYRIAD `.blob` формата 6.0. Исходники, CMake и тесты: `openvino-ncs2/`.
Инструкция сборки: `openvino-ncs2/README_RU.md`.
Старая библиотека OpenVINO и старый Python не нужны на голове.
Из исходников 2022.3.2 в новый плагин входят только mvnc/XLink для USB.

В программе `Soccer/Vision/neural.py` управляет приватным дочерним процессом
на том же новом Python; только ребёнок загружает `openvino.Core`. Это изоляция
нативных зависаний/аварий NCS2. Старый Python и отдельный устанавливаемый
сервис не нужны. BGR передаётся через один mmap, команды — через socketpair;
request переиспользуется. При отказе/таймауте ребёнок завершается, футбольное
зрение переключается на цветовой алгоритм без повторных попыток inference.
`ROKI_NCS2_TIMEOUT=1` с, `ROKI_NCS2_STARTUP_TIMEOUT=15` с по умолчанию.
Имя `neuro_client.py` оставлено как совместимый импорт. Подробности и тесты:
`docs/NCS2_RESILIENCE_RU.md` в репозитории приложения.

Из истории Roki_2_Soccer восстановлена модель `orange_ball_on_green_only` и
скомпилирована **настоящая `ball.blob`**. BGR U8 NHWC-вход, нормализация и
RGB-перестановка встроены в граф. Выход FP32 [1,25200,7]. В Python остаются
letterbox и YOLOv5 postprocessing. Артефакты и SHA256: `MODEL_BUILD_RU.md`.
Старый C++ compiler использовался только для подготовки blob вне головы.
Компиляция произвольного XML/ONNX самим новым плагином пока не поддерживается.

## Что проверено

- Настоящая библиотека собрана на macOS arm64, загружается OpenVINO 2026.0.0
  из Python 3.14.3 и зарегистрирована как MYRIAD. USB devices = []:
  физического NCS2 здесь нет.
- Native dependencies: новый OpenVINO, libusb и системные библиотеки;
  старый OpenVINO не подгружается в процесс.
- CTest проходит: parser/transfer (25 malformed inputs), интеграция с
  настоящими OpenVINO/Python и **отдельной тестовой имитацией USB**.
- Проверены import/export, padding, sync/async, несколько requests,
  соответствие ответов и отказ дальнейшего inference после таймаута.
- Parser/transfer также проверены AddressSanitizer + UndefinedBehaviorSanitizer.
- Готовая футбольная blob импортируется новым плагином и `Neural` приложения
  при тестовом транспорте. Это не выполнение сети на NCS2.

## Что остаётся проверить на голове

Сборка под конкретный Buildroot/CM4, USB firmware boot, выполнение модели,
качество распознавания, длительная работа и восстановление после USB-сбоев.
Доступ к голове и toolchain ещё не предоставлен; аппаратная работоспособность
**пока не подтверждена**. Нельзя выдавать тестовый USB-backend за устройство.

Для первого образа нужны OpenVINO **2026.0.0**, его bindings под Python образа,
libusb, numpy и OpenCV. Разместить plugin/ball.blob/firmware как описано в
`MODEL_BUILD_RU.md`, проверить через `tools/test/check_openvino_ncs2.py`.
Патчи, исходники плагина и артефакты теперь включены в каталог `buildroot/`
репозитория программы по запросу разработчика. Это материалы для интеграции
в существующую сборку образа, не готовый самостоятельный Buildroot external tree.
